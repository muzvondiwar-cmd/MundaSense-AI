# Data area

`sample/maize_demo.csv` is deterministic synthetic demonstration data generated by
`scripts/train_model.py`. It is not observed farm data and must not be used to claim field
accuracy. `raw/` and `processed/` are intentionally empty placeholders and ignore local files.

CSV ingestion is UTF-8 and comma-delimited. Required columns, units, provenance, missing-data
policy, and leakage notes are documented in `docs/data_dictionary.md` and `docs/data_sheet.md`.
